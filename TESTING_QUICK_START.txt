⚡ QUICK API TESTS (Copy-Paste)

Login & Get Token:
  curl -X POST http://127.0.0.1:8081/api/auth/login \
    -H "Content-Type: application/json" \
    -d '{"username":"superadmin","password":"Admin123!"}' | python3 -m json.tool

List Pegawai (20 staff):
  curl -X GET http://127.0.0.1:8081/api/pegawai \
    -H "Authorization: Bearer $TOKEN" | python3 -m json.tool

List Santri (1.300 students):
  curl -X GET http://127.0.0.1:8081/api/santri?limit=10 \
    -H "Authorization: Bearer $TOKEN" | python3 -m json.tool

List Bank Soal (10+ questions):
  curl -X GET http://127.0.0.1:8081/api/bank-soal \
    -H "Authorization: Bearer $TOKEN" | python3 -m json.tool
